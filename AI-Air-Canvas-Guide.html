How It Works

📺 Display
MediaPipe Hands detects 21 3D landmarks per hand at ~30 FPS. Landmark #8 (index fingertip) is tracked as your drawing cursor. A deque smoothing buffer averages the last 8 positions to eliminate jitter.

Setup in VS Code — Step by Step
1

Open the folder in VS Code

Go to File → Open Folder and select the AI-Air-Canvas folder. Or use the terminal:

code AI-Air-Canvas
2

Open the VS Code Terminal

Press Ctrl + ` (backtick) to open the integrated terminal at the bottom of VS Code.

3

Create a virtual environment

⚠️ Use Python 3.8–3.11. MediaPipe does not support 3.12 yet.

# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
After activation, you should see (venv) at the start of your terminal prompt.
4

Install dependencies

This installs OpenCV, MediaPipe and NumPy (~50 MB download).

pip install -r requirements.txt
5

Select the Python interpreter in VS Code

Press Ctrl + Shift + P → type Python: Select Interpreter → choose the one inside ./venv.

6

🚀 Run the project!

python air_canvas.py

A window called ✨ AI Air Canvas will open with your live webcam feed and the pink colour bar at the top.

Troubleshooting
❌ Cannot open webcam
Try changing cv2.VideoCapture(0) to (1) or (2) in air_canvas.py
❌ ModuleNotFoundError
Make sure you activated the venv first: venv\Scripts\activate (Windows) or source venv/bin/activate (Mac/Linux)
❌ MediaPipe install fails
Use Python 3.8–3.11. Check version: python --version
⚠️ Laggy / slow drawing
Lower resolution: change 1280 to 640 and 720 to 480 in air_canvas.py
⚠️ Hand not detected
Improve lighting — face a bright light source. Keep hand fully visible in frame.
